# AACHIP-ALTERA-SVF-PROGRAM

AACHIP ALTERA SVF PROGRAM 是針對 Altera／Intel 可程式邏輯裝置的 SVF 執行工具，透過 JTAG 介面執行檔案內的掃描指令，供裝置燒錄、組態設定及測試使用。

實際支援的 FPGA／CPLD、JTAG 硬體、SVF 指令及檔案產生方式，請參考各版本發布說明。

## 關於 SVF

SVF（Serial Vector Format）是一種描述 JTAG 操作序列的文字格式，可包含：

- TAP 狀態切換。
- 指令暫存器（IR）與資料暫存器（DR）掃描。
- TDI 資料輸出。
- 預期 TDO 資料與遮罩比對。
- 等待週期及時序控制。

上述為 SVF 格式的常見內容，不代表本軟體支援全部指令或語法。
透過INTEL quartus_cpf.exe 可以自動將SOF檔案轉換成SVF 及 BIN 檔案.燒錄速度高達30MHZ,看LAYOUT及電壓決定.
## 應用情境

- 執行適用於目標裝置的 SVF 燒錄流程。
- 載入 FPGA 組態或進行 CPLD 程式更新。
- 執行檔案定義的 JTAG 測試與資料比對。
- 協助開發測試、設備維護及重複燒錄作業。

實際操作結果取決於 SVF 內容與目標裝置；執行 SVF 不一定代表資料會永久保存。

## 基本使用流程

1. 安裝軟體及 JTAG 硬體所需的驅動程式。
2. 確認目標裝置型號、供電與 JTAG I/O 電壓。
3. 依硬體說明連接 TCK、TMS、TDI、TDO 及 GND。
4. 使用適用的開發工具，產生符合目標裝置及 JTAG 鏈配置的 SVF 檔案。
5. 啟動軟體，選擇 JTAG 裝置並設定適當時脈。
6. 載入 SVF，確認檔案與目標板相符後執行。
7. 檢查執行紀錄、資料比對及完成狀態。

## 相容性說明

- SVF 必須符合目標晶片及整條 JTAG 鏈的配置。
- 多裝置串接時，需正確處理裝置順序、IR 長度及 BYPASS。
- 不同開發工具或版本產生的 SVF，可能使用不同指令與時序需求。
- Quartus 產生 SVF 的操作方式及支援範圍，請依工具版本與裝置文件確認。

## 使用注意事項

- 執行前請確認 SVF 來源與用途，檔案可能包含抹除、燒錄或改變裝置狀態的操作。
- 執行期間保持供電與連線穩定，避免拔除硬體。
- JTAG 接線應盡量短；通訊不穩時可降低 TCK 頻率。
- 避免其他工具同時控制同一個 JTAG 介面。
- TDO 比對失敗時，請檢查接線、時脈、目標型號及 JTAG 鏈設定。
- FPGA 揮發性組態與非揮發性燒錄不同，是否能斷電保留取決於裝置及 SVF 執行的流程。
